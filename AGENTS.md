# Repository Agent Instructions

Before planning, implementing, reviewing, or refactoring, read and follow [`docs/development-principles.md`](docs/development-principles.md).

Read only the relevant sections of [`docs/engineering-playbook.md`](docs/engineering-playbook.md) and the applicable Accepted ADRs according to the change risk. Do not duplicate the development rules in this file. `docs/development-principles.md` is the project-wide engineering authority; the playbook provides detailed guidance without creating a separate rule source.
